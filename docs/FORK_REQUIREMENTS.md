## 1. 阅读页与阅读习惯

- **文本阅读习惯全局**：字体、字号、字距、行距、段距、缩进、简繁、背景、文字颜色、翻页动画均属全局 `ReadBookConfig`/`AppConfig`，不按书保存、不进入单书同步。
- **图片书例外**：翻页动画、图片样式、替换规则、模拟阅读起始章节、音频播放模式/速度可留在 `Book.readConfig`，但不参与习惯同步、不提供“本书阅读习惯”入口。
- **滚动阅读**：保存并恢复首个可见行；`onPause` 同步落库；划掉最近任务/强杀不得回退本地进度。
- **夜间/背景**：背景是全局白天/夜间设置，预设只作模板；跟随系统夜间模式切换后阅读页立即刷新。
- **返回键**：阅读页返回不暂停朗读；暂停态离开阅读页也不停止服务。
- **书架刷新/预下载**：不得因后台刷新/预下载把阅读页或 WebView 跳到别的页面（`#1336`）。
- **大屏/平板**：保留合入的分栏阅读能力（`#1441`）；手机保持单栏，后续上游改动不得破坏两种布局切换。

## 2. 听书交互（硬性，详见 `docs/FORK_DECISIONS.md` 1.2/1.3）

- 两套恢复入口：菜单“朗读/继续”从当前可见位置；App 悬浮胶囊继续暂停前位置。
  - 菜单入口不区分朗读服务是“未启动”还是“已暂停”，都不能复用 `readAloudLastPosition`；滚动模式取首个可见行，翻页模式取当前页起始。
- 页内浮条：跟随朗读时隐藏；手动浏览/退出跟随后显示“回到朗读位置 / 从这读”。
- 高亮只改文字颜色，不画黄色/任何背景块；墨水屏用下划线。
- 跟随中上下滑动 = 退出跟随并自由滚动/翻页，不拖动朗读位置；左右翻页由开关控制。
- 手动脱离跟随后，TTS 进度不得自动恢复跟随；只有回到朗读位置/从这读/新会话才恢复。
- 跟随中通过目录/进度条/上一章/下一章换章：朗读游标移到新章节并从新章节继续（暂停态保持暂停）；已脱离跟随后换章只翻页，不动朗读位置。回前台/解锁只在仍跟随时同步可见页。
- 通知媒体面板上一首/下一首 = 上一章/下一章；耳机媒体键仍按“上一段/下一段 或 上一章/下一章”开关。
- 章末由朗读服务单一接管；章节数取阅读页/会话较大值；TTS 无 `onDone` 有看门狗。
- 跟随播放后台换章强制落库，播放中最多 30 秒落一次；写库单调，旧位置不能覆盖新位置。
- 支持边听 A 书边读 B 书：B 页不得响应 A 的进度/浮条/高亮。

## 3. 下载、缓存与换源

- **手动批量缓存节奏**：前 3 章不额外等待，之后每章间隔 2 秒；分页正文书源批量并发 4，单章分页并发 4。
- **超时**：正文单页读/调用 120 秒，单章含分页总时长 180 秒；超时交给补源或延后重试。
- **验证源**：出现人机验证时用隐藏 WebView 尝试自动通过；验证源打标并在批量中限速；失败静默重试（20 秒），不要把验证页当正文。
- **失败章节**：主源失败延后重试一次；补源优先同域名源；请假/晚点更新等本身内容过短（<30 字）的章节失败不补源。
- **换源/刷新/删书**：必须停止旧 `bookUrl` 的批量队列，避免待下载重复累计和连接池被占满；换源加载目录要有总超时。
- **来源可信**：章节缓存需记录实际来源 sidecar；书源/章节 URL 域名不一致时按 URL 取源；同步不要单独覆盖 `origin/tocUrl`。
- **空目录**：书源目录为空不能被当成“全源下架”而禁用所有书源。

## 4. 同步、账号与备份

- 手机号即账号；首次绑定恢复服务端最新备份，之后靠实时同步补齐差异。
- HTTP 写 + WebSocket 通知 + HTTP 增量拉取；WS 必须保留 `/ws/msg/` 与 `/ws/legado/sync/` 两条路由。
- 删除书/分组/自定义源用墓碑；旧设备补推不能复活；重新添加需更新的时间戳。
- 正在阅读的书不自动应用远端进度，离开阅读后再应用。
- 配置结构升级递增 `LocalConfig.configSyncVersion`，触发一次全量拉取。
- 应用设置按 key LWW 同步，排除设备/凭据/路径/缓存类键（完整名单 `SettingsSync.kt`）。
- 本地进度比服务端新时启动回传，而不是被旧进度覆盖。
- 备份 zip 只是保底快照；局域网备份流程为“校验 → 先备份 → 恢复”，恢复后实时同步补齐。
- 不恢复/不合并：WebDAV、在线 TTS、本地密码引导、`servers.json` 等已删除配置。

## 5. 字体/TTS/资源

- 字体：后台 `FontPack` + OSS 目录，客户端按需下载并校验 sha256；APK 不内置 `assets/font/presets`。
- TTS：仅系统 TTS + 本地 sherpa-onnx 目录（`RemoteTtsEngines`）；不提供 `http` 类型/在线 TTS。
- 朗读引擎与音色全局一份，不出现“本书”选项；多音色用全局音色列表。
- 大模型下载不设 60 秒总超时；高速率播放需足够 AudioTrack 缓冲并对零写入重试。
- 字体/TTS 管理端页面、目录缓存、安装状态必须与客户端一致。

## 6. 数据与统计

- 阅读记录按 `deviceId + bookName + author` 归属，不同设备/作者不串数据；恢复旧备份时空设备 ID 映射到当前设备。
- 音频播放按“集”计量，朗读按“章”计量；通知、计时、睡眠定时文案不能混用。
- 删除/排除类操作要留显式恢复入口，不能动用户自建数据（自定义源、书签、高亮、替换规则）。

## 7. 明确拒绝的上游行为

- WebDAV 同步/备份、在线 TTS、本地密码引导、内置字体包、写死单一 TTS 模型、每本书一套阅读习惯/朗读引擎。
- 听书：黄色背景高亮、跟随中隐藏浮条、拖动定位代替上下滑退出、通知按段切章、`prevChapter` 只翻页、TTS 进度自动恢复跟随。
- 阅读：只异步写进度、启动只拉取服务端进度、后台下载失败覆盖当前已加载章节。
- 同步：用远端旧进度覆盖本地较新进度、删除后旧设备补推复活。
